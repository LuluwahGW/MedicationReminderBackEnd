# Medication Reminder app

A backend API built with using FastAPI SqlAlchemy for creating and managing users, caregiver, medications and reminder.

# Features
- user creation and management
- adding medication (name, dosage, selceted time)
- reminders (time, reminder text)
- caregivers linking system
